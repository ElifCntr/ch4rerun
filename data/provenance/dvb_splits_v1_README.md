# dvb_splits_v1.0 / scene-stratified session split / 2026-08-04

        Sessions move whole; scenes documented from the 2026-08-04 filename +
        thumbnail audit. Held-out (15 videos, 5 of 7 scenes) is scene-stratified.
        The published precedent partition (Akyon et al., AVSS 2021) was not
        recoverable: the paper states its 15 validation videos were randomly
        selected and does not name them, and no public repository carries the
        list; random video-level selection would in any case fail the
        session-integrity audit. This split supersedes the earlier manual split,
        rejected for session leakage (contiguous seaside timeline cuts and
        2019_10_16_C0003 segments straddling partitions). Fixed-wing airframes
        remain represented in train via the Parrot Disco family.
